[[printers.install_hplip]]
[.operation]
****
Install HPLIP, HP's printing and scanning drivers and tools (hplip, hplip-sane), for HP printers and all-in-ones.

*Command:* `/printers install-hplip` +
*Runs:* after you confirm. YAiST, or the assistant, first shows a plan with the commands it stands for.

.In the terminal, on Tumbleweed and Leap 16.0
[source,shell]
----
sudo zypper install hplip hplip-sane
----

.In the terminal, on Leap 16.1 Immutable
[source,shell]
----
sudo transactional-update --continue pkg install hplip hplip-sane
----
****

=== Add HP printer

// TODO(handbook): when and why to use this, then how it looks in YAiST.

// BEGIN GENERATED printers.add_hp -- written by `yaist docs` from the module's code; edit the code, not this block
[[printers.add_hp]]
[.operation]
****
Set up an HP printer or all-in-one with HPLIP (hp-setup), by IP address, hostname or USB serial number. Installs HPLIP first if needed.

*Command:* `/printers add-hp ADDRESS` +
*Runs:* after you confirm. YAiST, or the assistant, first shows a plan with the commands it stands for.

[horizontal]
`address`:: IP address, hostname or USB serial number (required)
`name`:: Name for the printer; HPLIP picks one if empty (optional)

.In the terminal, on Tumbleweed and Leap 16.0
[source,shell]
----
sudo zypper install hplip hplip-sane
sudo hp-setup -i -a -x ADDRESS
----

.In the terminal, on Leap 16.1 Immutable
[source,shell]
----
sudo transactional-update --continue pkg install hplip hplip-sane
sudo hp-setup -i -a -x ADDRESS
----
****
// END GENERATED

=== Add printer

// TODO(handbook): when and why to use this, then how it looks in YAiST.

// BEGIN GENERATED printers.add -- written by `yaist docs` from the module's code; edit the code, not this block
[[printers.add]]
[.operation]
****
Add a printer by its device URI with the driverless IPP Everywhere driver (works for most network and IPP-over-USB printers made since 2010).

*Command:* `/printers add NAME URI` +
*Runs:* after you confirm. YAiST, or the assistant, first shows a plan with the commands it stands for.

[horizontal]
`name`:: Name for the printer, e.g. Office (required)
`uri`:: Device URI, e.g. ipp://printer.local/ipp/print (see Find printers) (required)

.In the terminal
[source,shell]
----
sudo lpadmin -p NAME -E -v URI -m everywhere
----
****
// END GENERATED
