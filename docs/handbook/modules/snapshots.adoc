****

*Command:* `/snapshots create DESCRIPTION` +
*Runs:* after you confirm. YAiST, or the assistant, first shows a plan with the commands it stands for.

[source,shell]

=== Roll back

// TODO(handbook): when and why to use this, then how it looks in YAiST.

// BEGIN GENERATED snapshots.rollback -- written by `yaist docs` from the module's code; edit the code, not this block
[[snapshots.rollback]]
[.operation]
****
Make a snapshot the system that boots next (snapper rollback). Takes effect after a reboot; the current state stays available as a snapshot.

*Command:* `/snapshots rollback NUMBER` +
*Runs:* after you confirm. The plan is marked in red: this is hard to undo or changes what the system trusts, so read it before you agree.

[horizontal]
`number`:: Snapshot number, as listed (required)

.In the terminal, on Tumbleweed and Leap 16.0
[source,shell]
----
sudo snapper rollback NUMBER
sudo reboot
----

.In the terminal, on Leap 16.1 Immutable
[source,shell]
----
sudo transactional-update rollback NUMBER
sudo reboot
----
****
