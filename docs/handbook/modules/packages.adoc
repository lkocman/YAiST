=== Install

// TODO(handbook): when and why to use this, then how it looks in YAiST.

[[packages-conflicts]]
Sometimes the packages you ask for cannot be installed as they are: one
conflicts with something already on the system, or two of them provide
the same thing. zypper then offers ways out, and YAiST asks you about each
conflict in turn, with zypper's own solutions to pick from. Nothing is
installed until every conflict is settled and you have seen the summary.

[[fig-package-conflict]]
.A conflict while installing: one of three, with zypper's solutions
image::package-conflict.png[A package conflict dialog: "Package conflict 1 of 3", busybox-which conflicts with which, with zypper's solutions to pick from,pdfwidth=100%]


// BEGIN GENERATED packages.install -- written by `yaist docs` from the module's code; edit the code, not this block
[[packages.install]]
[.operation]
****
Install packages (and their dependencies). Where openSUSE has a pattern of the same name (e.g. hyprland, gnome, kde), the user picks between that complete setup and just the package.

*Command:* `/packages install PACKAGES` +
*Runs:* after you confirm. YAiST, or the assistant, first shows a plan with the commands it stands for.

[horizontal]
`packages`:: Package names, space separated (required)

.In the terminal, on Tumbleweed and Leap 16.0
[source,shell]
----
sudo zypper install PACKAGES
----

.In the terminal, on Leap 16.1 Immutable
[source,shell]
----
sudo transactional-update --continue pkg install PACKAGES
sudo reboot
----
****

=== Install Flatpak app

// TODO(handbook): when and why to use this, then how it looks in YAiST.

// BEGIN GENERATED packages.flatpak_install -- written by `yaist docs` from the module's code; edit the code, not this block
[[packages.flatpak_install]]
[.operation]
****
Install a Flatpak app for the current user (flatpak --user, no root). Sets up Flathub for the user if needed.

*Command:* `/packages flatpak-install APP` +
*Runs:* after you confirm. YAiST, or the assistant, first shows a plan with the commands it stands for.

[horizontal]
`app`:: Flatpak application ID, e.g. org.videolan.VLC (required)
`remote`:: Flatpak remote (default: `flathub`)

.In the terminal
[source,shell]
----
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user flathub APP
----
****
// END GENERATED

[[packages.update_system]]
[.operation]
****
Install all available updates: update the whole system the way this distribution expects (Leap: zypper update, or zypper dup while the release is in Alpha/Beta/RC; Tumbleweed/Slowroll: zypper dup; immutable: transactional-update into a new snapshot).

*Command:* `/packages update-system` +
*Runs:* after you confirm. The plan is marked in red: this is hard to undo or changes what the system trusts, so read it before you agree.

.In the terminal, on Tumbleweed
[source,shell]
----
sudo zypper dup --download-in-advance
----

.In the terminal, on Leap 16.0
[source,shell]
----
sudo zypper update --download-in-advance
----

.In the terminal, on Leap 16.1 Immutable
[source,shell]
----
sudo transactional-update --continue up
sudo reboot
----
****
