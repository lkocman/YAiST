[[services.list]]
[.operation]
****
List systemd services with their running and enabled state.

*Command:* `/services list` +
*Runs:* straight away; it only reads the system.

[horizontal]
`state`:: Which services to show: `all`, `running`, `failed`, `enabled` (default: `all`)
`filter`:: Only services whose name contains this text (optional)

.In the terminal
[source,shell]
----
systemctl list-units --type=service --all
----
****

[[services.status]]
[.operation]
****
Show one service's state, main process and recent log lines. Use this to diagnose a failing service.

*Command:* `/services status UNIT` +
*Runs:* straight away; it only reads the system.

[horizontal]
`unit`:: Service name, e.g. sshd or sshd.service (required)

.In the terminal
[source,shell]
----
systemctl status UNIT.service
----
****
// END GENERATED
