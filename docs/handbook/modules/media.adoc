[.operation]
****
Show what is set up for gaming and multimedia: graphics driver for the detected GPU, Steam, controllers, the SELinux gaming policy, codecs and Flathub.

*Command:* `/media status` +
*Runs:* straight away; it only reads the system.

.In the terminal
[source,shell]
----
lspci | grep -iE 'vga|3d'
rpm -q steam steam-devices selinux-policy-targeted-gaming
flatpak remotes --user
----

[[media.set_up]]
[.operation]
****
Set up one item of the gaming and media checklist: graphics (Vulkan driver, or NVIDIA drivers), non-oss (the repository Steam comes from on Tumbleweed), steam, controllers (steam-devices), selinux (gaming policy), gamemode, openh264 (official H.264 codec) or flathub.

*Command:* `/media set-up graphics` +
*Runs:* after you confirm. YAiST, or the assistant, first shows a plan with the commands it stands for.

[horizontal]
`item`:: What to set up: `graphics`, `non-oss`, `steam`, `controllers`, `selinux`, `gamemode`, `openh264`, `flathub` (required)

.In the terminal, on Tumbleweed
[source,shell]
----
# AMD: libvulkan_radeon libvulkan_radeon-32bit libvulkan1-32bit
# Intel: libvulkan_intel libvulkan_intel-32bit libvulkan1-32bit
# NVIDIA: sudo zypper install openSUSE-repos-Tumbleweed-NVIDIA && sudo zypper refresh-services && sudo zypper install-new-recommends
----

.In the terminal, on Leap 16.0
[source,shell]
----
# AMD: libvulkan_radeon
# Intel: libvulkan_intel
# NVIDIA: sudo zypper install openSUSE-repos-Leap-NVIDIA && sudo zypper refresh-services && sudo zypper install-new-recommends
----

.In the terminal, on Leap 16.1 Immutable
[source,shell]
----
# AMD: libvulkan_radeon
# Intel: libvulkan_intel
# NVIDIA: sudo transactional-update --continue run zypper install openSUSE-repos-Leap-NVIDIA && sudo transactional-update --continue run zypper refresh-services && sudo transactional-update --continue run zypper install-new-recommends
----

=== Set up gaming

// TODO(handbook): when and why to use this, then how it looks in YAiST.

[[media.set_up_gaming]]
[.operation]
****
Everything for gaming in one go: graphics driver for the GPU, Steam (RPM on Tumbleweed, Flathub Flatpak for the user on Leap and immutable systems), controller support and the SELinux gaming policy.

*Command:* `/media set-up-gaming` +
*Runs:* after you confirm. YAiST, or the assistant, first shows a plan with the commands it stands for.

.In the terminal, on Tumbleweed
[source,shell]
----
sudo zypper install steam steam-devices selinux-policy-targeted-gaming
# AMD: libvulkan_radeon libvulkan_radeon-32bit libvulkan1-32bit
# Intel: libvulkan_intel libvulkan_intel-32bit libvulkan1-32bit
# NVIDIA: sudo zypper install openSUSE-repos-Tumbleweed-NVIDIA && sudo zypper refresh-services && sudo zypper install-new-recommends
sudo zypper modifyrepo --enable openSUSE:repo-non-oss   # Steam is in non-oss
----

.In the terminal, on Leap 16.0
[source,shell]
----
sudo zypper install steam-devices selinux-policy-targeted-gaming
# AMD: libvulkan_radeon
# Intel: libvulkan_intel
# NVIDIA: sudo zypper install openSUSE-repos-Leap-NVIDIA && sudo zypper refresh-services && sudo zypper install-new-recommends
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user flathub com.valvesoftware.Steam
----

.In the terminal, on Leap 16.1 Immutable
[source,shell]
----
sudo transactional-update --continue pkg install steam-devices selinux-policy-targeted-gaming
# AMD: libvulkan_radeon
# Intel: libvulkan_intel
# NVIDIA: sudo transactional-update --continue run zypper install openSUSE-repos-Leap-NVIDIA && sudo transactional-update --continue run zypper refresh-services && sudo transactional-update --continue run zypper install-new-recommends
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user flathub com.valvesoftware.Steam
----
****

=== Full codecs (Packman)

// TODO(handbook): when and why to use this, then how it looks in YAiST.

// BEGIN GENERATED media.packman_codecs -- written by `yaist docs` from the module's code; edit the code, not this block
[[media.packman_codecs]]
[.operation]
****
Install full multimedia codecs from Packman, a third-party repository, with opi: switches ffmpeg, GStreamer and VLC codecs to Packman's builds. Not for immutable systems; Flatpak apps bring their own codecs instead.

*Command:* `/media packman-codecs` +
*Runs:* after you confirm. The plan is marked in red: this is hard to undo or changes what the system trusts, so read it before you agree.

.In the terminal
[source,shell]
----
sudo zypper install opi
opi codecs
----
****
