=== Add user

// TODO(handbook): when and why to use this, then how it looks in YAiST.

// BEGIN GENERATED users.create -- written by `yaist docs` from the module's code; edit the code, not this block
[[users.create]]
[.operation]
****
Create a local user account with a home directory. The account stays locked until a password is set.

*Command:* `/users create USERNAME` +
*Runs:* after you confirm. YAiST, or the assistant, first shows a plan with the commands it stands for.

[horizontal]
`username`:: Login name, lowercase, e.g. alice (required)
`full_name`:: Full name, e.g. Alice Smith (optional)
`admin`:: Make the user an administrator (member of wheel, can use sudo) (default: `false`)

.In the terminal
[source,shell]
----
sudo useradd --create-home USERNAME
sudo passwd USERNAME
----
****
// END GENERATED

[[users.delete]]
[.operation]
****
Delete a local user account, optionally with its home directory.

*Command:* `/users delete USERNAME` +
*Runs:* after you confirm. The plan is marked in red: this is hard to undo or changes what the system trusts, so read it before you agree.

[horizontal]
`username`:: Login name (required)
`remove_home`:: Also delete the home directory and mail spool (default: `false`)

.In the terminal
[source,shell]
----
sudo userdel USERNAME
----

[[users.add_to_group]]
[.operation]
****
Add a user to an existing group (supplementary membership; takes effect at the next login). Some groups give root-level access: wheel (sudo), docker, disk.

*Command:* `/users add-to-group USERNAME GROUP` +
*Runs:* after you confirm. YAiST, or the assistant, first shows a plan with the commands it stands for.

[horizontal]
`username`:: Login name (required)
`group`:: Group name, as listed by List groups (required)

.In the terminal
[source,shell]
----
sudo usermod --append --groups GROUP USERNAME
----
****
// END GENERATED
