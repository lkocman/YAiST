=== Add repository

// TODO(handbook): when and why to use this, then how it looks in YAiST.

// BEGIN GENERATED repos.add -- written by `yaist docs` from the module's code; edit the code, not this block
[[repos.add]]
[.operation]
****
Add a package repository by URL and trust its signing key. Only for sources the user trusts.

*Command:* `/repos add URL ALIAS` +
*Runs:* after you confirm. The plan is marked in red: this is hard to undo or changes what the system trusts, so read it before you agree.

[horizontal]
`url`:: Repository URL (https://…) (required)
`alias`:: Short unique name, e.g. games (required)

.In the terminal
[source,shell]
----
sudo zypper addrepo --refresh URL ALIAS
sudo zypper --gpg-auto-import-keys refresh --repo ALIAS
----
****
// END GENERATED

[[repos.add_obs]]
[.operation]
****
Add a community repository from the Open Build Service (e.g. home:user or devel:languages:rust), built for this distribution, and trust its signing key.

*Command:* `/repos add-obs PROJECT` +
*Runs:* after you confirm. The plan is marked in red: this is hard to undo or changes what the system trusts, so read it before you agree.

[horizontal]
`project`:: OBS project, e.g. games or devel:languages:rust (required)
`alias`:: Short unique name; defaults to the project name (optional)

.In the terminal, on Tumbleweed
[source,shell]
----
sudo zypper addrepo --refresh https://download.opensuse.org/repositories/PROJECT/openSUSE_Tumbleweed/ PROJECT
sudo zypper --gpg-auto-import-keys refresh --repo PROJECT
----

.In the terminal, on Leap 16.0
[source,shell]
----
sudo zypper addrepo --refresh https://download.opensuse.org/repositories/PROJECT/16.0/ PROJECT
sudo zypper --gpg-auto-import-keys refresh --repo PROJECT
----

.In the terminal, on Leap 16.1 Immutable
[source,shell]
----
sudo zypper addrepo --refresh https://download.opensuse.org/repositories/PROJECT/16.1/ PROJECT
sudo zypper --gpg-auto-import-keys refresh --repo PROJECT

=== Enable non-oss

// TODO(handbook): when and why to use this, then how it looks in YAiST.

// BEGIN GENERATED repos.enable_non_oss -- written by `yaist docs` from the module's code; edit the code, not this block
[[repos.enable_non_oss]]
[.operation]
****
Make sure openSUSE's non-oss repository is set up and enabled: freely distributable software that is not open source, such as Steam, some firmware and fonts.

*Command:* `/repos enable-non-oss` +
*Runs:* after you confirm. YAiST, or the assistant, first shows a plan with the commands it stands for.

.In the terminal, on Tumbleweed
[source,shell]
----
sudo zypper modifyrepo --enable openSUSE:repo-non-oss   # if it exists, disabled
sudo zypper addrepo --refresh 'http://cdn.opensuse.org/tumbleweed/repo/non-oss/' repo-non-oss   # if it is missing
----

.In the terminal, on Leap 16.0 and Leap 16.1 Immutable
[source,shell]
----
sudo zypper modifyrepo --enable openSUSE:repo-non-oss   # if it exists, disabled
sudo zypper addrepo --refresh 'http://cdn.opensuse.org/distribution/leap/${releasever}/repo/non-oss/$basearch' repo-non-oss   # if it is missing
----
****
