[[system.reboot]]
[.operation]
****
Restart the computer now, e.g. to finish updates installed into a new snapshot. Running programs are closed.

*Command:* `/system reboot` +
*Runs:* after you confirm. The plan is marked in red: this is hard to undo or changes what the system trusts, so read it before you agree.

.In the terminal
[source,shell]
----
sudo systemctl reboot
----
****

[[system.set_ntp]]
[.operation]
****
Turn automatic time synchronisation (NTP) on or off.

*Command:* `/system set-ntp` +
*Runs:* after you confirm. YAiST, or the assistant, first shows a plan with the commands it stands for.

[horizontal]
`enabled`:: Synchronise the clock over the network (default: `true`)

.In the terminal
[source,shell]
----
sudo timedatectl set-ntp true
----
